## 원본 6편에서 관찰한 화면 문법

1. **인물 컷 대부분이 초상이 아니라 신체 부위 컷.** 217프레임 중 깨끗한
   가슴 위 정면 초상은 3~4장. 입 매크로(스트립), 발(머리카락), 손(폰 POV,
   낙엽 문지르기), 뒷머리. 얼굴은 리액션 순간에만 — 그때도 아래에서
   올려보거나 눈밑 초근접으로 극단적으로 자름
2. **한 피사체를 8개+ 카메라 위치로 돈다** (쥐+통 편이 교과서: 위에서,
   옆 매크로, 통 안에서 밖으로, 수직 오버헤드, 유리 너머). 거리·높이·크롭이
   계속 변하는 것이 다이나믹의 실체 — 포즈가 아니다
3. **스케일 사다리 상시 왕복**: 우주→대륙→도시→사람(33초 안), 전신→피부
   매크로→모낭 단면→DNA. 인접 컷이 두 단 이상 점프
4. **전경 가림물이 거의 모든 컷에 있다**: 흐린 통 테두리, 이빨 사이로 본
   브로콜리, 어깨 너머. 깨끗한 피사체+배경 구도가 드물다
5. **오브젝트가 여정의 주인공**: 화살표가 8,000마일을 6초간 날고, 신호가
   척추를 오르고, 은유를 문자 그대로 짓는다(안전지대=통, 신경 게이트=차단봉).
   우리 진피=구슬 격자가 정확히 이 문법

## 튜토리얼 2편의 파이프라인 — 우리와 사실상 동일

대본(코퍼스 학습) → 캐릭터 이미지 먼저 → 이후 컷에 ref → 컷마다 first/end
이미지 → start+end 영상화(Kling 2.1) → 전환은 앞 영상 중간 프레임을 다음
first로(=우리 체인) → 실물 사진을 ref로(=우리 제품 ref) → ElevenLabs VO →
편집. **우리 구조가 틀리지 않았다는 검증.**

우리에게 없던 것 두 가지:

- **편집 후처리가 다이나믹의 상당 지분** (Dan Kieft가 ZDF 분석으로 명시):
  완성 클립 위에 편집에서 줌인을 얹고, 전환마다 스크린 셰이크, 전환부 색보정.
  생성 단계가 아니라 편집 단계의 레버 — 재생성 크레딧 0으로 기존 산출물에
  적용 가능
- **스타일 앵커 문구**: "semi-realistic 3D render, game engine cutscene
  style" (+ Pixar 명시 거부). 우리가 clip1 v1~v4로 도달한 "실사 90%+3D 10%,
  비율은 실물·표면만 CG"와 같은 지점의 한 줄 표현

기타: ElevenLabs 설정(mult-v2, speed 98%·stability 35%·similarity 75%),
컷별 SFX 프롬프트 생성(우리 AUDIO 블록이 이미 담당), 대본은 ZDF 대본
10편을 코퍼스로 GPT에 학습.

## 2026-08-11 추가 — 직역(사물화) 문법이 본체다

카메라 문법만 옮긴 1차 재설계에 사용자가 지적: ZDF의 핵심은 **이해가 쉽게
대사의 말을 실물로 화면에 세우는 것**이다. 예: "조명빨인가 했는데" → 화면에
실제 스탠드 조명을 두고, 불이 켜지며 밝아졌다가 **꺼져도 피부가 그대로
밝다** = 나레이션의 논리가 6초 안에 증명된다. 온라인 분석도 동일
("misunderstood process를 정밀 CGI로 시각화", high clarity가 인기 요인).

페이스오일 2세대에 적용한 직역 소품: 조명(2)·크림 병 대기(7)·빈 공간 속
작은 전신(6a)·인증 인장(10a)·달력 JUN→AUG(11a)·거대 3D 41%(16).
운용 규칙: **숫자·문자 소품은 이미지 단계에 박는다** (크롭 확대로 검수하고
싸게 재추첨 가능 — 영상 중 텍스트 생성은 검증 불가). 달력은 영문 약칭만
(한글은 깨진다). 공적 마크(식약처 로고)는 그리지 않고 일반화된 인장으로.
