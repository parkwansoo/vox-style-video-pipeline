# 설계 — Remotion 자막 레이어 (승인 대기, 미구현)

작성: 2026-08-04. 상태: **설계만 확정, 구현 착수 전.** 착수 시 이 문서를 그대로 따른다.

## Context

생성 모델은 화면 텍스트 오탈자에 취약해 지금까지 자막을 아예 뺐다 (TODO 2026-08-02). 반면 이 파이프라인의 `words.json`은 **대본 정본에 정렬된 어절 단위 타이밍**이라(whisper는 시간만 제공) HTML 렌더 자막은 오탈자가 원천적으로 없다. 숏츠 자동화 프로젝트에 검증된 한국어 자막 Remotion 구현이 이미 있어 이를 이식한다.

**사용자 확정 사항 (2026-08-04)**:
1. 숏츠자동화의 어절그룹 통자막 교체 구조를 따르되 **강조색 없이 흰 글자만**
2. 파이프라인에 단계 추가 + **기미 2편(20260802-melasma-vgshot)에 즉시 적용**
3. 워터마크 가림 배지는 이번에 안 함 (TODO 25번 유지)
4. 새 Remotion 프로젝트는 `npm create video@latest`로 시작 (기존 프로젝트 통복사 금지 — 사용자 피드백 메모)

**아키텍처**: final.mp4(720x1280, 24fps)를 Remotion `OffthreadVideo`(volume 1) 배경으로 깔고 자막만 얹어 h264로 `final_sub.mp4` 렌더 — 숏츠자동화 `--bg-video` 패턴(`20_숏츠 자동화/scripts/render-video.mjs:132-140`, 검증된 경로). 현 ffmpeg 빌드에는 subtitles/ass/drawtext 필터가 없어 ffmpeg 번인은 불가. **final.mp4는 덮어쓰지 않는다.**

**핵심 시간 매핑** (assemble.py 검증 완료): 나레이션은 배속 없이 클립 시작점에 재배치되므로(배속은 클립 비디오에만 적용), 챕터 타임라인 어절 시각 t에 대해

```
final_time = offset[i] + (t - seg_start[i])   # t를 포함하는 클립 i, rate로 나누지 않는다
```

offset은 정규화 클립 실측 길이의 누적합 — 프레임 양자화로 12클립 기준 +0.16s 드리프트가 실측되어 **assemble이 방출한 값만 사용**하고 seg_start에서 재계산하지 않는다.

## 구현 단계

### 1. assemble.py — timeline.json 방출
`.claude/skills/vox-video/scripts/assemble.py`
- 이미 계산 중인 durations/rates/offsets(101~143, 221~224행)를 `--out` 옆 `timeline.json`으로 **항상 기록** (stdout JSON 유지, 하위 호환)
- `--timeline-only` 플래그 신설: 클립 정규화까지만 수행해 timeline.json만 쓰고 종료 — **--out 파일 미접촉** (기존 final.mp4 보존용)
- 스키마: `{version, out, width, height, fps, trim, total_duration, clips:[{global, chapter, clip, file, narration, seg_start, seg_end, rate, offset, duration}]}`

### 2. Remotion 프로젝트 스캐폴드 — `subtitler/`
- 저장소 루트에서 `npm create video@latest` (디렉터리 subtitler, Blank 템플릿, TS). zod는 설치된 Remotion의 peer 요구 버전으로 고정(`npx remotion versions`로 경고 0 확인). `@remotion/fonts` 추가
- 루트 `.gitignore`에 `subtitler/node_modules/` 추가 (`*.mp4` 전역 무시라 렌더 산출물은 자동 제외, 폰트 .otf는 커밋)
- 폰트: `20_숏츠 자동화/outputs/audio/_fonts/GmarketSansBold.otf` → `subtitler/assets/fonts/` 복사

### 3. 컴포넌트 이식 (원본: `20_숏츠 자동화/remotion/`)

| 원본 | 대상 | 처리 |
|---|---|---|
| `Captions.tsx` | `subtitler/src/Captions.tsx` | 강조색·scenes 오버라이드 제거. 유지: 등장효과 8종, delayRender 폰트 게이트, `paintOrder:'stroke fill'`, `wordBreak:'keep-all'`, top% 중앙앵커, "공백은 span 밖" 패턴 |
| `fonts.ts` | `subtitler/src/fonts.ts` | 카탈로그를 G마켓산스 1종 인라인, Promise 캐시 유지 |
| `schema.ts` | `subtitler/src/schema.ts` | captionSchema(`{text,startMs,endMs}`) + 서브셋: 가로/세로/배경영상/영상길이ms/폰트/글자굵기/글자크기/글자색/외곽선색/외곽선두께/등장효과/효과세기/자막높이/안전여백/자막최대너비/자막목록 — **zod가 미선언 키를 strip하므로 전부 선언** |
| `Root.tsx` | `subtitler/src/Root.tsx` | **FPS=24** (소스와 일치), calculateMetadata로 크기·duration, **defaultProps는 `active-input.json` import 변수 참조** (스튜디오 자동저장 함정 차단 — Inspector "Resolve" 금지 주석) |
| 신규 | `subtitler/src/SubtitledVideo.tsx` | AbsoluteFill > OffthreadVideo(staticFile bg, volume 1, cover) + Captions |

- 스타일 기본값 `subtitler/config/caption-preset.json`: G마켓산스 / 굵기 800 / 글자크기 5(height%) / 흰색 #FFFFFF / 검정 외곽선 **4px**(1080 기준 5px의 720 보정) / fade+pop / 자막높이 65 / 안전여백 6

### 4. 자막 데이터 생성 — `subtitler/scripts/make-captions.mjs`
- `20_숏츠 자동화/scripts/lib/segment.mjs`(한국어 어미·조사 DP 줄바꿈, 공백 제외 16자, minDur 700ms)를 `subtitler/scripts/`에 **무수정 복사**
- CLI: `node subtitler/scripts/make-captions.mjs --run output/<run>`
- 알고리즘: timeline.json + 각 챕터 words.json 로드 → 어절을 클립에 배정(`seg_start≤start<seg_end`, 초과분 클램프) → 매핑 공식으로 최종 시각 변환 → **클립 그룹 단위로** segmentCaptions 호출(조각이 클립 경계를 안 넘음) → 전역 후처리(다음 조각 시작 침범 금지, 총길이 클램프) → `<run>/subtitle-props.json` + `subtitler/src/active-input.json` 동기화
- stdout 요약: 조각 수 · 최장 글자수 · 700ms 미만 조각 수

### 5. 렌더 — `subtitler/scripts/render.mjs`
- Node API (`@remotion/bundler`+`renderer`, render-video.mjs:110-161 미러): 스테이징 publicDir(`<run>/.subtitle-public/`에 final.mp4→bg.mp4 복사 + 폰트 — bundle()이 publicDir 전체를 복사하므로 run 폴더 전체를 publicDir로 잡으면 안 됨) → bundle → selectComposition('SubtitledVideo') → renderMedia(h264, crf 18) → `<run>/final_sub.mp4` (기존 파일은 .prev 백업)
- 렌더 후 자체 검증 내장: ffprobe로 오디오 스트림 존재 · duration ±0.15s · 720x1280 · 24fps

### 6. SKILL.md 갱신
- 7단계: timeline.json 상시 기록 + `--timeline-only` 설명
- **7.5단계 신설 "자막 (기본 ON)"**: make-captions → render 두 명령, 최초 1회 `cd subtitler && npm install`, 스타일은 caption-preset.json, **재합본 후에는 자막 재생성 필수**
- 8단계 검증 추가: 자막 싱크(조각 startMs+200ms 프레임 추출 대조 3~4곳) · 줄바꿈 · 잘림 · 오디오 확인. 전달물은 final_sub.mp4 기본

### 7. 기미 2편 적용 절차
1. `assemble.py --manifest .../manifest.json --out .../final.mp4 --size 720x1280 --timeline-only` (**--size 720x1280 필수** — 기본값 가로 함정, TODO 52번). 정합 검증: sum(duration) ≈ 기존 final 비디오 51.97s ±0.1, 클립 12개. 불일치 시 final_v2로 전체 재합본 후 그것을 자막 베이스로
2. make-captions → 스팟체크 (ch1 첫 어절 "미백" ≈ 0ms, ch2 첫 조각 = 클립7 offset 드리프트 반영값 ≈ 25.24s)
3. render → final_sub.mp4 → 프레임 추출 검증 후 사용자 눈검수

## 검증 (엔드투엔드)
- timeline.json: 클립 12, offset 단조증가, sum(duration) ≈ 51.97s
- final_sub.mp4: 오디오 스트림 존재, duration = final ±0.15s, 720x1280/24fps
- 싱크 4곳 프레임 추출: ch1 초반(드리프트 0) / ch1 끝(드리프트 누적) / ch2 첫(챕터 경계) / ch2 끝
- 사용자 최종 눈검수 후 채택 결정

## 이식 함정 (숏츠자동화 문서에서 실증된 것)
- **Studio Inspector "Resolve" 버튼 금지** — defaultProps 리터럴화 → 드래그 자동저장 오염 재발. defaultProps는 JSON import 변수 참조로 원천 차단
- Studio 사용 후 `git status`로 subtitler/ 워킹트리 오염 확인 (tsc·테스트가 못 잡는 유효 prop 오염 실사례 있음)
- zod는 미선언 키를 조용히 제거 — 새 prop은 반드시 schema.ts에도 선언
- word-stagger 효과에서 공백은 span 밖에 (inline-block 내부 후행 공백은 CSS가 접음)
- BGM 없음이라 interpolate 단조성 함정은 해당 없음
- 렌더 예상 2~6분 (1,248프레임, 720x1280) — onProgress 출력으로 진행 확인
