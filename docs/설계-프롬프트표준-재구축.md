# 설계 — 이미지 프롬프트 표준 재구축 + 라벨 5행 복원 + 배경 원칙

## 왜 이 작업이 필요한가 — 사고 경위

기미 오일 편 W0·W1 이미지 7장이 광범위하게 실패했다. 원인은 씬 설계가 아니라
**프롬프트 작성 단계**다.

검증된 표준이 **산출물에만 존재하고 문서에 없었다.** 지난 페이스오일 편
(`output/20260810-faceoil-review/ch1/clip*_img*.txt`, 36개)은 4블록 구조를
일관되게 썼고 결과가 좋았는데, 그 구조가 어떤 스킬 문서에도 적혀 있지 않다.
`pipeline-rules.md`의 이미지 템플릿은 Paper Diorama 계열용이고 mg-bodylab
계열은 "해당 없음"으로 되어 있어, 5단계 필수 문서를 다 읽어도 이 표준에
도달하지 못한다. 그래서 이번 세션은 씬 파일 번역만 근거로 프롬프트를 새로
썼고, 36/36에 있던 블록 두 개가 통째로 빠졌다.

**실측 (Codex는 이 수치를 재확인할 것)**

| 블록 | 지난 편 36개 중 출현 | 이번 편 내 프롬프트 |
|---|---|---|
| STYLE | 36 | **0** |
| RENDER MODE | 36 | **0** |
| AVOID | 36 | 7 (짧게) |
| STILL | 34 | 7 |
| WOMAN | 15 (인물 컷) | 0 |
| PRODUCT | 13 (제품 컷) | 2 |
| CAMERA | 11 | 0 |
| SCENE MATCH | 9 (체인) | 0 |
| CONTINUITY | 5 (쌍) | 0 |

이 누락이 낳은 실패:
- **실사 톤** (캐릭터 시트·A·D·F1) — RENDER MODE 블록 부재. 지난 편은
  "a frame from a 3D animated short film... NOT a photograph and NOT a
  cartoon" + 머리카락·피부 렌더 지시를 장문으로 넣어 실사를 눌렀다
- **병원 인테리어** (A) — STYLE 블록 부재로 배경이 씬 서술에 맡겨졌고,
  AVOID의 인테리어 금지("a room corner, floor, wall, furniture or any
  interior")도 없었다
- **인물 정면 응시** (A) — CAMERA 블록과 "centred, level, symmetrical
  portrait 금지" AVOID 부재
- **시트 인물 미반영** (D·F1) — 지난 편 인물 컷의 "Her skin RENDERING is
  taken directly from the 3D character faces shown on the attached style
  sheet — take ONLY the skin material" 문구 부재

## 이 작업의 원칙 (가장 중요 — 사용자 지시)

> "원본 프롬프트의 형식은 가장 기초 유지되어야 한다. 블럭과 구조는 최대한
> 유지하면서 우리가 개선한 것들을 반영했어야 했다. 이 부분은 가장 중요하니
> 한번에 진행하지 말고 깊게 고민해서 진행해야 한다."

따라서:

1. **지난 편 블록 구조와 원문이 기준선이다.** 새로 창작하지 않는다. 개선점은
   기존 블록 안의 슬롯이나 새 하위 항목으로 **얹는다.**
2. **원문을 요약·희석하지 않는다** (CLAUDE.md 규율 ④). 표준 문서에 옮길 때
   verbatim으로 옮기고, 어디를 바꿔 끼우는지만 슬롯으로 표시한다.
3. **단계마다 사용자 게이트가 있다.** 이 설계서의 산출물은 문서까지이며,
   실제 이미지 재생성은 사용자가 표준을 검수한 뒤에 시작한다.

## 산출물 1 — 프롬프트 표준 문서 (핵심)

**파일**: `.claude/skills/vox-video/references/prompt-standard.md` (신설)

### 작성 절차

**1단계 — 전수 분석.** `output/20260810-faceoil-review/ch1/`의 이미지 프롬프트
36개(`clip*_img*.txt`, `_분할전_*` 포함)를 **전부 읽는다.** 표본 몇 개로
일반화하지 않는다. 각 파일에서:
- 블록 순서와 헤더를 기록
- STYLE·RENDER MODE·AVOID의 **문장 단위 공통분모**를 추출한다 (거의 모든
  파일에 동일하게 반복되는 문장 = 불변 원문, 컷마다 달라지는 문장 = 슬롯)
- 컷 유형을 분류한다: 인물(WOMAN) / 제품(PRODUCT) / 단면·스킨레이어 /
  피부 매크로 / 손+제품 / 체인(SCENE MATCH) / 쌍(CONTINUITY)

**2단계 — 문서화.** 아래 구조로 쓴다:

1. **이 문서가 있는 이유** — 위 "사고 경위"를 3~4줄로. 표준이 산출물에만
   있으면 다음 편에서 또 유실된다는 것이 요지
2. **블록 구조표** — 순서 / 필수·조건부 / 지난 편 출현 실적(36개 중 N)
3. **블록별 기준 원문** — STYLE, RENDER MODE, AVOID(공통 항목)를 **원문
   그대로** 싣고, 컷마다 바뀌는 자리는 `[슬롯: 설명]`으로 표시. 원문이
   길다고 줄이지 않는다 — 이 문서의 가치는 원문 보존이다
4. **컷 유형별 레시피** — 유형마다 ①필요한 블록 조합 ②그 유형 전용 원문
   (WOMAN 블록의 시트 얼굴 패널 직지 문장, PRODUCT 블록, SCENE MATCH 문형)
   ③그 유형 전용 AVOID 추가 항목
5. **AVOID 라이브러리** — 공통 항목(전 컷)과 유형별 추가를 분리해 목록화.
   각 항목이 어떤 실측 사고에서 왔는지 한 줄 근거를 붙인다
6. **개선점 삽입 지점** — 아래 "얹을 개선점" 참조
7. **미결 결정** — 아래 "사용자 결정 대기" 참조
8. **관찰 중 (v1)** — 이 표준의 첫 실전이 기미 오일 편 재작업임을 명시

**3단계 — 연결.** `.claude/skills/vox-video/SKILL.md` 5단계에서 이 문서를
**반드시 읽도록** 연결한다 (기존 `pipeline-rules.md` 필독 문장 옆에, 같은
어투로 한 문장 추가). CLAUDE.md의 "작업 전에 읽을 것" 표에도 행 추가.

## 산출물 3 — 배경 3층 원칙

**문제**: 씬 파일이 컷마다 배경을 서술해서(예: 씬 1a "화이트 벽+블루 패널의
단순화 클리닉") 병원 인테리어가 그려졌다. 지난 편은 정반대였다 — STYLE
블록이 모든 컷을 블루 시클로라마에 올리고, AVOID가 인테리어를 금지했다.

**원칙 (사용자 확정 2026-08-14)**: 배경은 3층으로 나눈다.

1. **STYLE 블록(표준)이 배경을 전담한다** — 이음새 없는 블루 시클로라마,
   지평선·모서리·바닥 없음. 전 컷 불변
2. **씬 파일은 화면에 있어야 할 인물·사물만** 적는다 (씬 1a면: 시술 베드,
   누운 주인공, 의사의 팔·장갑 손, 레이저 장비). 배경 서술을 쓰지 않는다
3. **AVOID가 인테리어를 금지한다** — 지난 편 원문 이식

수정 대상:

1. `output/20260813-melasma-oil/ch1/scenes/공통설정.md`
