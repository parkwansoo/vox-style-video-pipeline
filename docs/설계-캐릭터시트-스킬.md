# 설계 — character-sheet 스킬 (편별 인물 캐릭터 시트)

작성 2026-08-14. 구현: Codex / 구현 후 검수: Claude 세션 / 발주: 사용자.

## 배경과 목적

인물 얼굴이 나오는 편에서 정체성 고정을 지금은 컷 체인에 의존한다 —
첫 인물 컷(기미 편의 B)이 나온 뒤에야 그것을 앵커로 삼고, 얼굴 정보가
많은 보조 앵커(D)는 체인 중간에야 생긴다. 이 구조는 ①앵커의 얼굴 정보가
적고 ②인물 컷들이 직렬화되며(B🔒→D🔒→F1→F2) ③표정 지시가 텍스트만으로
약하다.

캐릭터 시트는 생산 시작 전에 인물을 다각도·다표정으로 고정하는 **identity
control asset**이다 (beauty portrait가 아니다 — 원 지시문의 취지 유지).
제품 컷에 `assets/products/<제품>/SPEC.md`가 있듯, 인물 컷에 시트가 생긴다.

## 확정된 설계 결정 (사용자 확정 2026-08-14 — 임의 변경 금지)

1. **편별 자산이다.** 작업 폴더(편)마다 인물이 새로 정의되고 시트도 그 편
   전용이다. 프로젝트 공용 코어 시트는 만들지 않는다 (과잉 설계로 기각).
   같은 인물을 다음 편에 다시 쓰려면 지난 편 시트를 새 시트 생성의 ref로
   첨부하면 족하다 — 별도 인프라 없음.
2. **저장 위치**: `output/<run>/ch<N>/character/` — `SHEET.png`(시트),
   `PLAN.md`(계획+최종 프롬프트+게이트 기록). git 추적 밖(output/).
3. **구성 (한 장, 패널 7~9개)**:
   - 정체성 패널: 정면 / 이야기에 필요한 쪽의 3/4 / 같은 쪽 프로필 /
     전신(편 의상 착용) / (스토리 소품 있으면) 손 클로즈업
   - 감정 패널 3~4개: **씬 파일의 감정 서술을 원문 번역**해서 만든다
     (예: 기미 편이면 실망(씬 2 "눈물 없음")·근심(씬 6)·옅은 미소(씬 12)
     + 중립). 수위 = "빠른 컷에서 즉시 읽히는 과장" — 만화적 일그러짐 금지
   - **중립 피부**: 기미·건조 같은 씬 상태는 시트에 박지 않는다 — 상태는
     컷별 텍스트가 결정한다 (시트에 박으면 모든 컷을 그 상태로 끌고 간다)
   - 원 지시문의 패널 11개는 과밀(패널당 해상도 하락)로 축소 확정
4. **렌더 톤**: 활성 스타일 시트를 ref로 첨부해 같은 렌더 세계로 만든다.
   원 지시문의 `photorealistic` 하드코딩은 제거 — 우리 스타일(soft-lit 3D,
   never photographic)과 정면 충돌하고, 실사 시트는 컷 생성 때 스타일
   시트 ref와 싸운다.
5. **생성 시점**: 씬 설계 완료 후 ~ 5단계(이미지 생산) 전. 감정 비트와
   편 의상이 씬 설계에서 나오므로 이 자리가 유일하게 맞다.
6. **게이트 2회**: ①PLAN 작성 후 사용자 확인(계획 게이트) ②시트 생성 후
   사용자 검수(인물 확정 게이트). 게이트 ② 통과 후 시트는 **그 편에서
   불변 정본** — 재생성 금지, 수정은 게이트 단계에서 끝낸다 (편 중간에
   시트가 바뀌면 이미 만든 인물 컷들과 어긋난다).
7. **다운스트림(인물 컷) ref 구성**: 스타일 시트 + 캐릭터 시트
   (+ 체인 프레임) + **제외 목록 필수** — 시트의 그리드 레이아웃·패널
   배치·엉뚱한 패널의 표정이 컷에 유출되는 것을 막는다.
8. **관찰 중 v1 표기**: 표본 0이다. 3D 렌더 톤의 시트 품질 / ref 다중
   첨부 시 지배력 / 그리드 유출 여부는 관찰 항목으로 스킬에 명시하고,
   규칙 승격은 표본이 쌓인 뒤로 보류한다.

## 산출물 1 — 새 스킬 `.claude/skills/character-sheet/SKILL.md`

형식·밀도는 `.claude/skills/style-sheet/SKILL.md`를 본보기로 한다
(먼저 읽고 같은 어투·구조로 쓸 것: 절대 원칙 → 번호 절차 → 비용).

### 문서 구조

1. **목적 한 단락** — identity control asset, not a beauty portrait.
   편별 자산임을 명시.
2. **절대 원칙 4개**: ①편별 자산 (프로젝트 공용 아님) ②게이트 ② 통과 후
   불변 — 재생성 금지 ③중립 피부 — 씬 상태는 컷 텍스트가 결정 ④활성
   스타일 렌더 세계 — photorealistic 금지
3. **절차**:
   - 0단계 사전 점검: 씬 설계(공통설정 포함) 완료 여부 / 활성 스타일 시트
     존재(`assets/style_reference.png`) / 얼굴 나오는 컷 유무(없으면 이
     스킬 불필요 — 종료)
   - 1단계 씬 파일에서 추출: 인물 정의(공통설정), 편 의상, 감정 비트
     (씬별 감정 서술 **원문**), 이야기에 필요한 방향(카메라 접근 측 —
     기미 편이면 오른쪽), 스토리 소품(손 패널 필요 여부)
   - 2단계 CHARACTER SHEET PLAN 작성 → **사용자 확인 (게이트 ①)**.
     양식은 원 지시문의 Output 블록을 유지하되 2행 추가:

     ```
     CHARACTER SHEET PLAN

     Identity lock:
     Story role:
     Main outfit:
     Required expressions:   ← 씬 번호와 함께 (예: disappointment — scene 2)
     Required details:
     Direction:              ← 추가 (이야기에 필요한 측. 예: right side)
     Render tone:            ← 추가 (활성 스타일명 + soft-lit 3D 등 시트 문법)

     Image prompt:
     ```
   - 3단계 프롬프트 조립 (아래 개정 템플릿)
   - 4단계 생성: 기존 이미지 생성 경로(ChatGPT 구독)와 동일. 첨부 ref =
     활성 스타일 시트 (+ 참조 얼굴이 있으면 그 이미지, 지난 편 시트 재사용
     시 그 시트)
   - 5단계 자기 검증 체크리스트: 패널 구성이 PLAN과 일치 / 패널 간 동일
     인물(얼굴·머리·체형) / 글자·라벨·워터마크 없음 / 렌더가 스타일 시트와
     같은 세계 / 씬 상태(기미 등)가 피부에 없음
   - 6단계 **사용자 게이트 ② (인물 확정)** → 통과 시 `character/` 폴더에
     저장, PLAN.md에 게이트 기록, 이후 불변 정본 선언. 실패 시 게이트
     단계에서 수정·재생성 (최대 2회 — style-sheet 스킬과 같은 상한, 이후
     사용자 보고)
4. **다운스트림 사용 규칙** (인물 컷 프롬프트에서):
   - 첨부: 스타일 시트 + 캐릭터 시트 (+ 체인 프레임)
   - 제외 목록 필수: 시트의 그리드 레이아웃·패널 배치·배경·목표가 아닌
     패널의 표정
   - 표정 지시는 시트의 해당 패널을 가리킨다 (예: "the worried expression
     as shown in the character sheet") — ref가 표정을 끌고 오는 성질의
     역이용 (pipeline-rules 7절 참조)
   - AVOID에 추가: 시트의 격자 구성·복수 패널이 컷에 나타나는 것
5. **관찰 중 (v1)**: 결정 8 항목의 관찰 목록 그대로.
6. **비용**: 시트 1장 = 이미지 생성 1회 (재시도 최대 2회).

### 개정 프롬프트 템플릿 (스킬에 수록, 영문)

원 지시문 기반. 수정점: photorealistic 제거·렌더 슬롯화, 패널 축소,
방향 슬롯, 중립 피부, 부트스트랩 두 모드.

```text
[참조 얼굴이 있을 때만 첫 줄 포함:]
Use the attached face image as the face, hairstyle, and body proportion
reference. Preserve the same person throughout the sheet.

Create a clean character sheet of the same [character role],
rendered in the same visual style as the attached style reference sheet
([렌더 톤 — 예: soft-lit dimensional 3D, never photographic]).

Identity:
[face identity], [hair], [body proportion], [overall impression],
clean neutral skin without scene-specific conditions.

Outfit:
[main outfit], [key accessories], [story-critical prop if needed].

Sheet layout ([N] panels):
front face,
[direction] three-quarter face,
[direction] profile,
full body in the main outfit,
neutral expression,
[expression 1 — 씬 파일 원문 번역],
[expression 2],
[expression 3],
[optional: close-up of hands showing [detail]].

Background:
plain light neutral studio backdrop, soft even lighting,
clean reference sheet layout.

Do not change the face between panels.
Do not change the hairstyle or body type between panels.
Do not add extra people.
Do not add text, panel labels, logos, watermarks, or UI.
```

원 지시문의 Wardrobe Rules 4줄(의상은 이야기 시점에 맞춤 / 과잉 디자인
금지 — 단순한 의상이 영상 모델에서 더 잘 보존 / 스토리 소품은 직접 포함 /
소품이 중요하면 클로즈업 패널 요청)은 취지 그대로 스킬에 옮긴다.

## 산출물 2 — 시스템 반영 4곳

기존 문구는 원문 유지, 추가는 최소 삽입. 각 파일을 먼저 읽고 기존 형식
(체크박스·절 번호·어투)을 따른다.

1. `.claude/skills/vox-video/references/scene-design.md`
   - 공통설정 작성 규칙 부근에 추가: 인물 얼굴이 나오는 컷이 있으면
     캐릭터 시트를 만든다 — character-sheet 스킬 참조, 시점은 씬 설계
     완료 후 ~ 5단계 전
   - "편 수준 마무리 검수" 체크리스트에 항목 추가: 캐릭터 시트
     생성·게이트 완료 (얼굴 컷 있는 편만) + 제작대장에 시트를 자산으로
     등재하고 인물 컷들의 선행 조건에 연결
2. `.claude/skills/vox-video/SKILL.md` 5단계 (클립 이미지 생성)
   - 인물 컷의 ref 구성에 캐릭터 시트 추가 (스타일 시트 + 캐릭터 시트 +
     체인 프레임 + 제외 목록), `.claude/skills/character-sheet/SKILL.md`
     참조 링크
3. `.claude/skills/vox-video/references/pipeline-rules.md` 7절
   (정체성 레퍼런스 운용)
   - 캐릭터 시트가 있으면 그것이 정체성 ref 정본임을 추가. 첨부 시 제외
     목록(그리드·패널 배치·비목표 패널 표정)과 표정 패널 지시 역이용,
     그리드 유출 AVOID를 이 절의 기존 어투로 추가
4. 프로젝트 `CLAUDE.md`의 "작업 전에 읽을 것" 표에 행 추가:
   `| 인물 얼굴이 나오는 컷 | .claude/skills/character-sheet/SKILL.md |`
   (제품 컷 행과 같은 층위)
